# 分数的计算

## 倒数

**乘积为 $1$ 的两个数互为倒数**。求倒数就是把分子分母倒过来。

$$\frac{a}{b} \times \frac{b}{a} = 1$$

- $\frac{2}{3}$ 的倒数是 $\frac{3}{2}$
- 整数 $n$ 的倒数是 $\frac{1}{n}$
- $1$ 的倒数是 $1$
- $0$ 没有倒数（乘什么都是 $0$，凑不出 $1$）

## 乘法

$$\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}$$

分子乘分子，分母乘分母，不用通分。

$$\frac{2}{3} \times \frac{4}{5} = \frac{8}{15}$$

能约就先约（交叉约）：

$$\frac{3}{8} \times \frac{4}{9} = \frac{1}{2} \times \frac{1}{3} = \frac{1}{6}$$

## 除法

除以一个数就是乘它的倒数。

$$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}$$

$$\frac{5}{6} \div \frac{10}{3} = \frac{5}{6} \times \frac{3}{10} = \frac{1}{4}$$

## 加法

分母一样时，分母不动，只把分子相加：

$$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

$$\frac{1}{3} + \frac{1}{3} = \frac{2}{3}$$

分母不一样时，先通分成同分母：

$$\frac{a}{b} + \frac{c}{d} = \frac{a \times d}{b \times d} + \frac{b \times c}{b \times d}$$

$$\frac{1}{2} + \frac{1}{3} = \frac{3}{6} + \frac{2}{6} = \frac{5}{6}$$

## 减法

和加法一样，只是把分子相减。同样要先同分母。

$$\frac{7}{8} - \frac{1}{6} = \frac{21}{24} - \frac{4}{24} = \frac{17}{24}$$

## 约分

分子分母同除一个不为 $0$ 的数，分数大小不变。

$$\frac{a}{b} = \frac{a \div k}{b \div k}$$

$$\frac{12}{18} = \frac{2}{3}$$

算到最后要约成**最简分数**（分子分母互质）才算完。

## 带分数

先化成假分数再算加减乘除。

$$2\frac{1}{3} = \frac{2 \times 3 + 1}{3} = \frac{7}{3}$$

## 易错点

**1. 异分母不能直接加分子**

$\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$，不是 $\frac{2}{5}$。

**2. 同分母时分母别跟着加**

$\frac{1}{3} + \frac{1}{3} = \frac{2}{3}$，不是 $\frac{2}{6}$。

**3. 倒数不等于相反数**

$\frac{2}{3}$ 的相反数是 $-\frac{2}{3}$，倒数是 $\frac{3}{2}$。

倒过来只翻分子分母，**符号不动**：$-\frac{2}{3}$ 的倒数是 $-\frac{3}{2}$。

**4. $0$ 的问题**

$\frac{0}{5} = 0$，但 $0$ 没有倒数；$\frac{5}{0}$ 本身没有意义。

**5. 分数线上下各自带括号**

$\frac{1+2}{3+4} = \frac{3}{7}$，不是 $1 + \frac{2}{3} + 4$。

## 例题

**例 1** 计算 $\frac{1}{4} + \frac{2}{3} \times \frac{3}{8}$

先算乘法：

$$\frac{2}{3} \times \frac{3}{8} = \frac{1}{4}$$

再算加法：

$$\frac{1}{4} + \frac{1}{4} = \frac{1}{2}$$

**例 2** 一个数的 $\frac{2}{3}$ 是 $12$，求这个数

$$12 \div \frac{2}{3} = 12 \times \frac{3}{2} = 18$$

**例 3** 比较 $\frac{5}{6}$ 和 $\frac{7}{8}$ 的大小

通分到 $24$：

$$\frac{5}{6} = \frac{20}{24}
\qquad
\frac{7}{8} = \frac{21}{24}$$

$21 > 20$，所以 $\frac{7}{8} > \frac{5}{6}$。

**例 4** 计算 $\frac{3}{4} \div \frac{9}{16}$

$$\frac{3}{4} \div \frac{9}{16} = \frac{3}{4} \times \frac{16}{9} = \frac{4}{3}$$

---

乘除直接算，加减先通分，最后约到最简。
