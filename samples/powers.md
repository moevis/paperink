# 幂运算的性质

一句话：**乘方就是「几个相同的数相乘」的简写**。

## 一、三个名字

以 $a^n$ 为例：

- **底数** $a$：被乘的那个数
- **指数** $n$：连乘的次数
- **幂**：乘完得到的结果

展开就是 $n$ 个 $a$ 连乘：

$$a^n = a \times a \times \cdots \times a$$

$a^n$ 读作「$a$ 的 $n$ 次方」，也可以读「$a$ 的 $n$ 次幂」。

## 二、七条基本性质

设 $a \ne 0$，$b \ne 0$，$m$、$n$ 为正整数：

- **同底相乘**：$a^m \times a^n = a^{m+n}$，指数相加
- **同底相除**：$a^m \div a^n = a^{m-n}$，指数相减
- **幂的乘方**：$(a^m)^n = a^{mn}$，指数相乘
- **积的乘方**：$(a \times b)^n = a^n \times b^n$
- **商的乘方**：$(a \div b)^n = a^n \div b^n$
- **零指数**：$a^0 = 1$
- **负整数指数**：$a^{-n} = \frac{1}{a^n}$

七条的来路只有一条：指数记的是「乘了几次」。相乘就把次数加起来，再乘方就把次数再乘一遍。记不住就退回这条。

## 三、为什么 $a^0 = 1$

按「同底相除，指数相减」：

$$\frac{a^3}{a^3} = a^{3-3} = a^0$$

而 $\frac{a^3}{a^3}$ 就是自己除自己，显然等于 $1$。所以规定 $a^0 = 1$，前提 $a \ne 0$。

## 四、为什么负指数是倒数

同样按指数相减：

$$\frac{a^2}{a^5} = a^{2-5} = a^{-3}$$

而按分数约分，$\frac{a^2}{a^5}$ 等于 $\frac{1}{a^3}$，所以：

$$a^{-n} = \frac{1}{a^n}$$

注意：负指数让**整个幂取倒数**，不是让底数变号，也不会让结果变负——$2^{-3} = \frac{1}{8}$，不是 $-8$。

## 五、分数指数（拓展）

前提 $a > 0$：

$$\sqrt[n]{a} = a^{1/n}
\qquad
\sqrt[n]{a^m} = a^{m/n}$$

例：$8^{2/3} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$。

为什么要求 $a > 0$？因为 $\sqrt{-8}$ 不是实数，没有哪个实数的平方等于 $-8$。

## 六、易错点（丢分都在这）

**1. 负号在括号外，不参加乘方**

$(-2)^2 = 4$，而 $-2^2 = -(2^2) = -4$。差一个括号，差一个正负号。

**2. $(a+b)^n \ne a^n + b^n$**

$(2+3)^2 = 25$，而 $2^2 + 3^2 = 13$。乘方**不能**拆进加减法，只有乘除能拆：$(a \times b)^n = a^n \times b^n$。

**3. 同底相乘是指数相加，不是相乘**

$2^3 \times 2^2 = 2^{3+2} = 2^5 = 32$，不是 $2^6$。只有幂的乘方才把指数相乘：$(2^3)^2 = 2^6$。

**4. $a^0 = 1$ 有前提**

要求 $a \ne 0$，$0^0$ 没有意义。

**5. 负指数不是负数**

$2^{-3} = \frac{1}{8}$，指数上的负号表示取倒数，不表示符号。

**6. 分数指数的底数必须为正**

$(-8)^{1/3} = -2$ 在实数里成立，但 $(-8)^{1/2}$ 不是实数。做题时默认 $a > 0$。

## 七、运算顺序

1. 有括号先算括号
2. 再算乘方，然后乘除，最后加减
3. 只有**同底数**的幂才能合并指数

## 八、例题

**例 1** 化简 $a^3 \times a^5 \div a^2$

同底数，指数直接加减：

$$a^3 \times a^5 \div a^2 = a^{3+5-2} = a^6$$

**例 2** 计算 $(2x^2y)^3$

积的乘方，每个因式分别乘方：

$$(2x^2y)^3 = 2^3 \times (x^2)^3 \times y^3 = 8x^6y^3$$

**例 3** 化简 $(a^2)^3 \times a^{-4}$

先算幂的乘方，再合并：

$$(a^2)^3 \times a^{-4} = a^6 \times a^{-4} = a^{6-4} = a^2$$

**例 4** 计算 $2^{-2} + (-3)^0$

$$2^{-2} + (-3)^0 = \frac{1}{4} + 1 = \frac{5}{4}$$

**例 5** 比较 $2^{30}$ 与 $3^{20}$

指数不同、底数也不同，先化成同指数：

$$2^{30} = (2^3)^{10} = 8^{10}$$

$$3^{20} = (3^2)^{10} = 9^{10}$$

底数 $9 > 8$，所以 $3^{20} > 2^{30}$。

---

以上性质对整数、分数、小数的底数都成立，只要满足各条对底数的要求：除法的分母不为 $0$，开偶次方时底数为正。
